# すずき美容室 ホームページ

江戸川区小松川「すずき美容室 hair make salon」の公式ホームページです。
特別なソフトは不要で、ファイルを書き換えて保存するだけで更新できます。

---

## 1. ファイルの中身

| ファイル | 中身 |
|---|---|
| `index.html` | ページ本体（文章・料金・住所など） |
| `css/style.css` | 色・文字の大きさなど見た目 |
| `js/main.js` | メニューの開閉などの動き（ふだん触らなくてOK） |
| `data/news.json` | **お知らせ・定休日**（よく更新する所） |
| `data/voices.json` | お客様の声 |
| `images/` | 写真を入れるフォルダ |

---

## 2. インターネットに公開する（GitHub Pages・無料）

最初に1回だけ行います。

1. [GitHub](https://github.com/) で無料アカウントを作ります。
2. 右上の「＋」→「New repository」を押し、名前を `suzuki-hairsalon` にして「Create repository」。
3. 「uploading an existing file」をクリックし、このフォルダの中身（`index.html` や `css` フォルダなど）を**全部まとめて**ドラッグ＆ドロップして「Commit changes」。
4. 上のメニューの「Settings」→ 左の「Pages」を開きます。
5. 「Branch」を `main`、フォルダを `/ (root)` にして「Save」。
6. 1〜2分待つと、同じ画面に `https://（アカウント名）.github.io/suzuki-hairsalon/` というURLが表示されます。これがホームページのアドレスです。

> 公開URLは `https://fishboy88.github.io/suzuki-hairsalon/` です（index.html に設定済み）。独自ドメインにしたときはここを書き換えてください。

### 更新するとき
GitHubの画面で更新したいファイルを開き、右上の鉛筆マーク（Edit）で直して「Commit changes」を押すだけです。1〜2分でホームページに反映されます。

## 3. お知らせ・定休日を更新する（`data/news.json`）

1つのお知らせは `{ }` で囲まれたかたまりです。いちばん上に新しいかたまりを足します。

```json
[
  {
    "date": "2026-12-01",
    "tag": "定休日",
    "title": "12月の定休日のお知らせ",
    "body": "12月1日（火）、8日（火）…はお休みをいただきます。"
  },
  {
    "date": "2026-11-01",
    ……（前からあるお知らせ）
  }
]
```

**注意点**
- `"` （ダブルクォーテーション）は半角のまま消さないでください。
- かたまりとかたまりの間には半角の `,`（カンマ）が必要です。**最後のかたまりの後ろにはカンマを付けません。**
- 日付は `2026-12-01` の形で書きます。新しい日付から順に自動で並びます（最大6件表示）。
- `tag` は「定休日」「七五三」「お知らせ」など自由に書けます。いらなければ `""` にします。

うまく表示されないときは、カンマや `"` の付け忘れがほとんどです。

## 4. 料金を変更する（`index.html`）

`index.html` の中で `★料金の変更はこのあたり` と書かれた所の下に料金があります。

```html
<li><span>大人カット</span><b>¥3,500</b></li>
```

`¥3,500` の部分だけ書き換えます。メニューを増やすときは、この1行をコピーして下に貼り、名前と金額を変えます。
七五三・袴・着物レンタルの料金は「特別な日のお支度」の所（`id="special"`）にあります。

## 5. 写真を差し替える

いまは写真の代わりに「写真：店内の様子」などのグレーの枠が出ています。

1. 写真を `images` フォルダに入れます（例：`hero.jpg`）。ファイル名は**半角英数字**にしてください。
2. `index.html` で差し替えたい枠を探します。例：
   ```html
   <div class="ph" data-label="写真：店内の様子"></div>
   ```
3. この1行を次のように書き換えます。
   ```html
   <img src="images/hero.jpg" alt="すずき美容室の店内">
   ```
   `alt` には写真の説明を書きます（目の不自由な方の読み上げや検索に使われます）。

**写真のコツ**
- スマホで撮った写真で十分です。横長がおすすめ。
- 1枚 500KB 以下に縮めると表示が速くなります（[TinyPNG](https://tinypng.com/) などで無料で縮められます）。
- SNSで共有されたときの画像は `images/ogp.jpg`（横1200×縦630くらい）を用意すると表示されます。
- お客様が写る写真は、必ずご本人の了承を取ってから載せてください。

## 6-2. Instagramの最新写真を表示する（最初に1回だけ）

「最近のスタイル」の欄に、Instagramの**最新3件**が自動で表示されます。Instagramに投稿すれば、ホームページを触らなくても入れ替わります。
無料サービス「Behold（ビホールド）」を使います。

1. [behold.so](https://behold.so/) を開き、無料アカウントを作ります。
2. 「Connect Instagram」から、**お店のInstagram（@suzuki_localhairsalon）でログイン**して連携を許可します。
3. 新しいフィードを作り、種類は **JSON** を選びます。
4. 表示された **フィードURL**（`https://feeds.behold.so/…` の形）をコピーします。
5. `index.html` で `data-feed=""` を探し、`""` の中に貼り付けて保存します。
   ```html
   <section class="sec insta" id="instagram" data-feed="https://feeds.behold.so/xxxxxxxx">
   ```

**知っておくこと**
- 無料プランで取得できるのは最新6件までです（ホームページには3件表示）。
- 新しい投稿がホームページに出るまで、少し時間がかかることがあります。
- フィードURLが空のまま、またはうまく取れないときは、写真の代わりに「Instagramでもっと見る」ボタンだけが表示されます（ページが崩れることはありません）。
- 動画（リール）は表紙の画像が表示されます。

## 7. 色を変えたいとき

`css/style.css` のいちばん上にある `:root { … }` の色コードを変えると、サイト全体の色が変わります。

| 名前 | 色 | 使っている所 |
|---|---|---|
| `--paper` | 白練 `#F4F3EF` | 地の色 |
| `--ai` | 藍 `#1E2B44` | 文字、「特別な日」とフッターの背景 |
| `--rose` | 桜鼠 `#B98E8B` | 差し色（線・ボタン） |
| `--gold` | 金茶 `#A88552` | 「こだわり」の細い線 |

## 8. 写真の形と動きについて

- 写真はサロンの鏡をイメージした**アーチ型**に自動で切り抜かれます。縦長の写真がいちばんきれいに収まります。
- ページを開くと、写真が下からせり上がり、縦書きのキャッチコピーが一行ずつ現れます。
- スクロールすると写真や文章がふわっと現れます。
- スマホやパソコンで「視差効果を減らす」「動きを減らす」設定をしている方には、動きを止めて最初から全部表示します。
- 「特別な日のお支度」はスマホでは横にスワイプして見る形です。
